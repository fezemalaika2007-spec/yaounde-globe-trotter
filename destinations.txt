 #To add new destinations manually without missing any images, follow these simple steps:

#1. How to format new entries in destinations.txt (Recommended)
#When adding a new destination, include its exact image address right on the header line using the pipe (|) symbol:

#text
# Destination 7: Place Name | Image_Address_URL
#Google_Maps_Place_URL
#How to get the Image Address:
#Open the place on Google Maps in your browser.
#Right-click on the main photo of the place.
#Click "Copy image address" (the URL will start with https://lh3.googleusercontent.com/...).
#Paste that URL after the | symbol.
#Example:
#text
# Destination 7: Bois Sainte Anastasie | https://lh3.googleusercontent.com/gps-cs-s/AHRPTW...
#https://www.google.com/maps/place/Bois+Sainte+Anastasie/...

#If you don't put the image URL in destinations.txt, you can add the name (in lowercase) and image address inside services/recommendation-service/parse_and_sync_destinations.py under KNOWN_PLACE_PHOTOS:
